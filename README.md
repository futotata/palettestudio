# Palette Studio — Androidタブレット・右利き色塗り練習向けペイントツール

CLIP STUDIO PAINT（クリスタ）の6種カラーパレットと色塗りワークフローを再現した、**Androidタブレット・右利き操作特化**のPWAペイントツールです。

## 主な特徴

- **右利きエルゴノミクス画面配置**
  - **画面右側**：カラーパレット（単一タブ表示 / 上下2段ドック表示をワンタップ切替）＋折りたたみ式レイヤーパネル
  - **画面左端**：左手親指用クイックバー（Undo/Redo、押している間だけ切り替わるホールド式スポイト、ブラシサイズ・不透明度の縦スライダー、左右反転表示など）
- **CLIP STUDIO PAINT準拠の6機能カラーパレット**
  1. **カラーサークル**：HSV（四角形）とHLS（固定三角形：縦＝輝度、右頂点＝純色）の切替に対応
  2. **カラースライダー**：HSV / HLS / RGB の動的予測グラデーションスライダー＋HEX入力
  3. **カラーセット**：よく使うカラーセットの`★`お気に入りピン留め、空白区切りマス、色名リスト表示、**JSON形式でのインポート・エクスポート**
  4. **近似色**：縦軸・横軸に任意の要素（H / S / V / L / R / G / B）を割り当てて周辺色を展開、基準色ロック機能付き
  5. **中間色**：四隅の基準色タイルからグリッド補間（Oklab知覚混色 / RGB線形補間）
  6. **カラーヒストリー**：実際にキャンバスへ描画・塗りつぶした色のみを自動記録
- **色塗り練習特化の描画・レイヤー機能**
  - **4系統の塗りブラシ**：Gペン/丸ペン、ソフトエアブラシ、下地の色を拾って伸びる厚塗り混色ブラシ、水彩なじませ
  - **参照レイヤー対応バケツ塗り**：線画を「参照レイヤー」に指定し、下のレイヤーへ隙間なく下塗り可能（領域拡縮対応）
  - **クリッピング＆合成モード**：下のレイヤーでクリッピング、透明ピクセルロック、乗算・スクリーン・オーバーレイ・加算発光など
  - **線画読込＆「輝度を透明度に変換」**：白背景の線画画像をワンタップで白いフチのない透明線画レイヤーへ変換
  - **サブビュー（お手本・資料窓）**：資料画像を並べて確認し、触れるだけで直接色をスポイト採取可能
  - **ペン専用パームリジェクション**：Sペン等のスタイラス検知で1本指の誤タッチ描画を防止し、2本指での移動・拡大縮小・回転・2本指タップUndoに対応

## Androidタブレットへのインストール（GitHub Pages）

1. GitHubリポジトリの **Settings ＞ Pages** で **Source** を **GitHub Actions** に設定します。
2. `main` ブランチへのプッシュで自動的にビルド・デプロイされます（URL例：`https://futotata.github.io/palettestudio/`）。
3. Androidタブレットの **Chrome** で公開URLを開き、右上メニュー（`⋮`）から **「アプリをインストール」**（または「ホーム画面に追加」）を選択すると、フルスクリーンのスタンドアロンPWAとしてオフラインでも利用できます。

## ローカル開発・起動方法

```bash
npm install
npm run dev -- --host
```

同一Wi-Fi内のAndroidタブレットから表示されたローカルIPのURL（例：`http://192.168.x.x:5173`）をChrome等で開き、ブラウザメニューの **「ホーム画面に追加（アプリをインストール）」** を選ぶとフルスクリーンPWAとして利用できます。
